# 10. Three-Day Preparation Plan

## Day 1 — Architecture + healthcare

### Morning

- Review the main architecture image.
- Practice drawing it from memory 3 times.
- Study Epic Clarity, Caboodle and FHIR basics.

### Afternoon

- Review ADF vs Databricks.
- Review Bronze/Silver/Gold.
- Review ADLS, private endpoints, Key Vault, managed identities.

### Evening

Practice a 5-minute architecture explanation without notes.

**Goal:** explain the end-to-end platform clearly and simply.

## Day 2 — Engineering + AI/ML

### Morning

Practice scenarios:

- SFTP failure
- incremental load
- CDC
- watermark
- deduplication
- schema drift
- reconciliation

### Afternoon

AI/ML:

- feature engineering
- MLflow
- feature store concept
- model registry
- batch vs streaming inference
- model/data drift
- responsible AI

### Evening

Do 10 rapid-fire technical questions.

**Goal:** answer with tradeoffs, not definitions only.

## Day 3 — Leadership + mock interview

### Morning

Practice:

- multiple concurrent engagements
- architecture disagreement
- difficult engineer/client
- unrealistic deadline
- executive communication

### Afternoon

Run the full 60-minute mock interview.

### Evening

Review weak areas only. Do not learn 20 new technologies the night before.

**Goal:** sound structured, calm, pragmatic and senior.

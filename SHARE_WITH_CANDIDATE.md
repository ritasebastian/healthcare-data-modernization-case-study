# How to Use This Repository

If you only have a few hours:

1. Open `README.md`.
2. Study the architecture image.
3. Read `docs/01_case_study_strategy.md`.
4. Read `docs/06_ai_ml_genai_strategy.md`.
5. Run the mock interview in `docs/08_mock_interview_60min.md`.
6. Review `docs/09_whiteboard_cheatsheet.md` just before the interview.

The goal is not to memorize product names. The goal is to show structured architectural judgment.
